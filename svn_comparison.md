# Сравнение Git и SVN

### 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
В Git ветка — это просто легковесный указатель (текстовый файл размером 41 байт со ссылкой на хеш коммита). Создание ветки происходит мгновенно и не расходует дисковое пространство. 
В SVN ветвление реализовано через полное копирование директории проекта на центральном сервере, что требует времени, создаёт дополнительную нагрузку на сеть и серверное хранилище.

### 2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет, нельзя. SVN является централизованной системой управления версиями. Локальная рабочая копия не содержит истории проекта — коммит отправляется непосредственно на центральный сервер. В отличие от SVN, Git является распределённой системой: у каждого разработчика хранится полная локальная база данных, поэтому коммиты делаются локально в офлайн-режиме.

### 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
1. Работа с огромными бинарными файлами (тяжёлая графика, 3D-модели, сборки видеоигр), где хранение полной копии всей истории на машине каждого разработчика перегружает диск.
2. Необходимость частичного чекаута (загрузка только одной папки из гигантского монорепозитория, а не всего проекта целиком).
3. Гранулярное разграничение прав доступа на уровне отдельных поддиректорий репозитория.
