# Заметки: IDE vs CLI при работе с Git

## 3 вещи, которые удобнее делать в VS Code (IDE):
1. Визуальный просмотр diff (наглядно подсвечиваются изменения по строкам).
2. Разрешение merge-конфликтов с выбором веток в один клик.
3. Наглядная история строк через расширение GitLens (git blame).

## 1 вещь, которую удобнее делать в терминале (CLI):
1. Работа со сложными сценариями (интерактивный rebase, stash, работа на удалённых серверах по SSH).
